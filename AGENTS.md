# Core Signal website design guardrails

Core Signal is the signal/insight product inside the Core Platform family.

## Family relationship

- Parent brand: Core Platform.
- Sibling product: CoreLink.
- Shared destination for documentation: docs.coreplatform.ir.
- Keep cross-navigation visible so Signal never feels like an unrelated company or microsite.

## Visual direction

Use the principles behind Leonxlnx/taste-skill `brandkit` and `taste-skill` when extending this site:

- Avoid generic SaaS card walls, decorative gradients without semantic purpose, default glassmorphism and arbitrary motion.
- Visual metaphors should come from signal processing: pulse, amplitude, anomaly, correlation, stream, focus and routing.
- Prefer restrained composition and high contrast over visual noise.
- Motion may clarify detection or state transitions, but must respect `prefers-reduced-motion`.
- Keep the parent family's typography, spacing rhythm, dark neutral base and navigation model.

## Product accent

- Core Signal accent: warm coral.
- Core Platform accent: acid-lime.
- CoreLink accent: cyan.

Use color semantically; do not turn every section into a different palette.

## Content rules

- Do not claim production capabilities that are not backed by implementation/release evidence.
- Describe the product model precisely: sources → observe → detect → signal → route/action.
- Prefer operational language over vague AI or "smart platform" marketing.
